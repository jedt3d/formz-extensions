# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Needs information before further work |
| ready-for-agent | ready-for-agent | Specified for agent work once blockers are satisfied |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Create missing labels only. Preserve existing labels and their descriptions. Triage readiness does not mean that a blocked ticket is executable.
