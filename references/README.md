# Local reference collection

This directory separates downloaded form·Z extensions and prebuilt plugins from active project source. The original package contents remain local and Git-ignored because their redistribution terms have not been established. A fresh clone includes these notes and the catalog, not those packages.

- `extensions/`: existing packages plus folders created for formerly loose scripts, archives, and platform binaries.
- `LABPrimitives_8_0_0_3/`: original OSX, Windows_32, and Windows_64 package layouts.
- [INVENTORY.md](INVENTORY.md): package directory names and file counts.
- [ORGANIZATION.md](ORGANIZATION.md): moves and grouping of loose files.

The collection contains `.fsl` script source, `.fsb` compiled scripts, `.fzp` plugins, `.fzr` resources, icons, archives, and documentation. Keep companion assets with their package. Existing numbered Curve_To_Arcs directories and both random-transform directories remain separate; their names alone do not establish that they are interchangeable.

Use these files for reference after reading their own headers and documentation. Before adopting a package into an active project, establish authorship, distribution terms, required form·Z version and platform, source availability, and an independent validation procedure. The catalog does not assert compatibility or successful execution.
